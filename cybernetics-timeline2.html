1993

Edinburgh Modular Arm System: The first bionic prosthetic arm in history, developed in 1993. An inventor named David Gow was the lead inventor in a development team that build this prosthetic arm in Endinburgh Scottland. This arm was built in the Bioengineering Centre at the Margaret Rose Hospital.

2007

i-LIMB Hand: An advanced myoelectric prosthetic hand that was built by Touch Bionics. This prosthetic hand was one of the first bionics with multiple joints and is known for motorized fingers and realistic grip patterns.

2014

Engineering Stage: The engineering stage helps deliver a manufactured, functional prototype that helps reach goals for the requirements of the user, and will be ready for validation.

2015

Testing Stage: The duration after the prototype has been constructed before it goes into full development. The testing stage purpose is to make sure the device is safe for the user to use.

2016

Deployment: This Stage is where the prosthetic is ready for the user to be able to operate it. The deployment stages allows the user to safely perform every day tasks.

2026

Motorica Omni Hand: A bionic hand that instead of using surface electromyography, it uses optical myography. The optical sensor control allows smoother, and more natural motion for users that have weak muscle activity. The hand was announced in November 2025, but is not set for mass production until 2026.
